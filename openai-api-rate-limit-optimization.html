API 密钥保管：不要写进代码与聊天记录

一把密钥，可能连着一笔不小的账单。保管密钥，是开发者的基本功。

常见的错误

  • 把密钥直接写进代码并提交到仓库。
  • 在聊天软件或工单里发送完整的密钥。
  • 多个项目共用同一个密钥。

正确的做法

使用环境变量或专门的密钥管理服务，在配置文件里只引用变量名。把含密钥的文件加入忽略列表。

权限最小化

为每个项目生成独立的密钥，只授予需要的权限，并设置使用额度与告警。

定期轮换

设定轮换周期，人员变动时立即更换相关密钥。

泄露后怎么办

第一时间到服务商后台吊销该密钥，生成新密钥，检查近期的调用记录与账单，并清理代码仓库的历史记录。
