隐私政策 (Privacy Policy)

以纯内存物理隔离架构，坚决践行零日志无痕通信承诺

1. 明确承诺：零活动日志留存 (No-Logs Policy)

隐云机场郑重声明：本平台全面执行严格的“零网络活动日志”策略。在您连接本服务专线节点的全部时段内，我们绝对不收集、记录、存储或分析您的任何网络行为数据。

具体而言，我们不会记录：

  • 您的真实来源物理 IP 地址、地理坐标或 ISP 信息；
  • 您所访问的任何目标网站 URL、DNS 查询记录或 API 调用数据；
  • 您在网络中传输的任何数据包正文内容与会话元数据；
  • 您的连接发起与断开的时间戳。

2. 纯内存（RAM-Only）运行架构机制

隐云机场的所有节点物理服务器均采用先进的“RAM-Only（纯内存操作系统）”架构。所有路由分发程序均在易失性内存中独立运行，服务器未配置物理磁盘写入权限。数据包在传输完毕后，相关的临时网络套接字立即被内存垃圾回收机制物理擦除。一旦服务器断电或遭遇常规重启，任何运行态缓存瞬间化为虚无，确保没有任何数据痕迹能够在物理介质上留存。

3. 极简账户运营数据范围

为了确保正常的订阅计费和提供必要的用户服务，我们仅在主数据库中存储以下基础信息：

  • 注册联系邮箱：用于接收账号密码找回与紧急维护通知，允许使用全匿名邮箱；
  • 已用流量汇总计数：仅为单纯的数字累加值，用于统计当前计费周期的配额进度；
  • 方案到期时间戳：用于维持服务周期的正常计时。

4. 端到端强密码学防护

从用户客户端到隐云专线出口，全部通信数据流均经过符合现代工业级密码学规范的加密协议（包括但不限于 AEAD 密码学组件）进行封装。任何中间路由节点或公网监听者仅能观测到混淆后的无规律数据流，有效阻断任何形式的深度报文检测（DPI）。
